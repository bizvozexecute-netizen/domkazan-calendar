# DomKazan Calendar

Основа отдельной системы занятости и цен загородных домов для [domkazan116.ru](https://domkazan116.ru/). Основной сайт и контент остаются на Tilda. Здесь пока нет онлайн-оплаты, автоматического подтверждения брони или переноса контента.

## Локальный запуск

Требуется Node.js 20.19+, 22.12+ или 24+, а также Docker с Compose либо собственный PostgreSQL. Команды ниже запускаются из корня проекта.

1. `npm install`
2. Скопируйте `.env.example` в `.env`. Замените все демонстрационные значения. Для локального Docker можно оставить пример `DATABASE_URL` и пароль из `compose.yaml`; они предназначены только для разработки.
3. Создайте случайный `SESSION_SECRET` длиной не менее 32 символов и укажите почту администратора в `ADMIN_EMAIL`. Выполните `node scripts/hash-password.mjs` и скопируйте выведенный хеш в `ADMIN_PASSWORD_HASH`. Пароль не сохраняется в репозитории.
4. `docker compose up -d postgres` (или запустите свой PostgreSQL).
5. `npm run db:migrate` и `npm run db:generate`.
6. `npm run dev`; откройте `http://localhost:3000/admin`.

Для существующей базы на сервере используйте `npm run db:deploy` вместо `db:migrate`. Перед запуском в продакшене настройте HTTPS и секреты в переменных окружения сервера. `.env` игнорируется Git.

## Модель данных

- `House`: дом, вместимость, активность, ссылка на страницу дома на Tilda.
- `BaseRate`: базовая цена за ночь в рублях, диапазон дат и минимальный срок проживания.
- `DateOverride`: цена для одной даты, перекрывающая базовый тариф.
- `BlockedPeriod`: закрытый интервал дат.
- `BookingRequest`: заявка клиента и её ручной статус. Только `CONFIRMED` блокирует даты в поиске.

Все периоды используют полуоткрытый формат `[заезд, выезд)`: день выезда снова доступен. Для каждой ночи нужен базовый тариф; без него дом не появляется в результатах. При пересечении базовых тарифов применяется тариф с самым поздним началом. Редактор тарифов должен запрещать такие пересечения при дальнейшем развитии админки.

## API и Tilda

`GET /api/availability?checkIn=2026-11-01&checkOut=2026-11-03&guests=4` возвращает доступные дома и общую стоимость в рублях. Даты в формате `YYYY-MM-DD`, срок от 1 до 60 ночей. Ошибки ввода возвращают HTTP 400. Ответ не кешируется. CORS разрешён только для точного origin из `TILDA_ORIGIN`.

Отдельный встраиваемый модуль находится в `public/embed/domkazan-search.js`. После размещения этого приложения на своём домене пример HTML-блока Tilda:

```html
<div data-domkazan-search data-api-url="https://calendar.example.invalid/api/availability"></div>
<script src="https://calendar.example.invalid/embed/domkazan-search.js" defer></script>
```

Замените демонстрационный домен на адрес приложения и установите `TILDA_ORIGIN=https://domkazan116.ru`. При использовании варианта сайта с `www` укажите именно тот origin, с которого загружается страница. Виджет только ищет дома и ведёт на страницы Tilda; заявку через него пока отправить нельзя.

## Проверки

`npm run lint`, `npm run typecheck`, `npm test`, `npm run build`. Для сборки нужен `DATABASE_URL` в окружении и предварительно сгенерированный Prisma Client. Тесты не используют персональные данные и не подключаются к базе.

## Следующие этапы

Нужны формы админки для домов, тарифов, исключений, закрытых периодов и ручной обработки заявок; проверка конфликтов при редактировании; интерфейс отправки заявки и согласованный процесс её подтверждения. Деплой и встраивание в действующий сайт выполняются отдельно.
